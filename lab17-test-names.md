# Lab 17 — Expressive Test Names

## Pattern
<method>_<scenario>_<expectedOutcome>

## Three names
1. activate_prospect_customer_transitions_to_active
2. activate_missing_customer_throws_not_found
3. activate_active_customer_throws_illegal_transition

## Anti-names rejected
testActivate, test1, activateWorks, activateCustomerTest — too vague, no scenario, no expected behavior encoded.

## Scope
Pre-lab only.
